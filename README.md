# Machine Learning Projects: Finance & Retail

This repository showcases my work in both **Supervised** and **Unsupervised** Machine Learning, applying data science techniques to solve real-world problems in the finance and retail sectors.

---

## 🏦 1. Credit-Wise Loan Prediction (Supervised Learning)
**Goal:** Predict whether a loan shouldbe Approved or Rejected before final human verification.

* **Type:** Classification
* **Dataset:** `loan_approval_data.csv`
* **Key Techniques:**
    * Handling imbalanced data.
    * Feature engineering for credit scores.
    * Algorithm: Logistic Regression, KNN Classifier, Naive Bayes Classifier.
* **Impact:** Helps financial institutions automate risk assessment and speed up the approval process.

---

## 🛒 2. SmartCart Customer Segmentation (Unsupervised Learning)
**Goal:** The system will analyse historical customer transacti on data and group customers into meaningful clusters based on purchasing behaviour, engagement levels, and loyalty indicators. 

* **Type:** Clustering
* **Dataset:** `smartcart_customers.csv`
* **Key Techniques:**
    * Determining optimal clusters using the **Elbow Method**.
    * Algorithm: **K-Means Clustering**.
* **Impact:** Identifies "Whale" customers (high value) and potential churn risks for targeted promotions.
